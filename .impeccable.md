## Design Context

### Users
The exhibit organizer operates a Windows laptop for a friend's interactive installation.
Visitors use a physical hold-to-record button; the organizer configures three independently
looping speakers. The operator needs clear feedback and quick adjustments during playback.

### Brand Personality
Clear, calm, practical. The user explicitly wants fewer sliders and an app that is easier
to follow, read, and understand.

### Aesthetic Direction
A restrained native desktop control panel. Group playback and recording setup separately,
use readable labels and spacing, and keep run state and primary actions visible.

### Design Principles
- One selected speaker, one shared set of volume and echo controls.
- Make it explicit which physical output is being edited.
- Keep Start/Stop and status visible independently of the selected setup tab.
- Preserve live control and recording reliability; avoid decorative motion or extra dependencies.
- Retain familiar native keyboard navigation and direct-click sliders.
